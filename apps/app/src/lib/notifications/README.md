# Notification assets

`notification-chime.wav` — the sound played when the app sends a notification.

- Source: https://pixabay.com/sound-effects/
- License: Pixabay Content License — commercial use allowed, no attribution required.
- Processed for the bundle: trimmed to 250 ms, downmixed to mono 44.1 kHz, normalized to -3 dBFS, 20 ms fade-out.
