# Spacing

**`globals.css` declares no spacing tokens.** The system uses Tailwind v4's single base unit, `--spacing: 0.25rem`, and derives every step from it: `p-4` resolves to `calc(var(--spacing) * 4)` = `1rem`.

Steps below are the ones the components actually reach for; any positive multiple is valid.

<SpacingScale />

## Rules

- Use the scale — `gap-2`, `p-4`, `space-y-6`. Never an arbitrary pixel value.
- Prefer `gap` on a flex or grid container over margins between siblings.
- Half steps (`0.5`, `1.5`, `2.5`, `3.5`) exist for control internals only, not for layout rhythm.
