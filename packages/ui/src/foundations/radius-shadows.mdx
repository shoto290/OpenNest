# Radius & Shadows

## Radius

One source value drives the whole scale:

```css
--radius: 0.625rem;
```

The `@theme inline` block derives `sm` through `4xl` from it with multipliers (`0.6` to `2.6`), so changing `--radius` reshapes every component at once. `rounded-xs` is the one step that is *not* derived — it keeps the Tailwind default of `0.125rem`.

## Shadows

**`globals.css` declares no shadow tokens.** The system uses the Tailwind v4 default elevation scale as-is. Introducing custom shadow tokens is a design decision, not a story author's call.
