# Colors

Every swatch reads its live CSS variable, so this page follows the theme toolbar. Switch to **Theme layout → Side by side** to compare light and dark at once.

Tokens are declared in `src/styles/globals.css`: light values on `:root`, dark overrides on `.dark`. Use the Tailwind utility (`bg-primary`, `text-muted-foreground`) rather than the raw variable.

## Feedback

`--destructive` has no `-foreground` pair — components use it as a text colour or as an alpha background (`bg-destructive/10 text-destructive`), never as a solid surface with text on top.
