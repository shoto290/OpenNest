# Conversation

The transcript with an agent and everything that happens inside it — turns, the composer, the payloads a turn renders, and the interruptions that need an answer. Nothing here makes sense in a product with no agent in it; a component that does belongs to another family.

## Message

The transcript and its turns.

- **ChatEmptyState** — no conversation open yet.
- **ConversationEmptyState** — a conversation with no turns yet.
- **EmptyStateShell** — the frame both empty states are drawn in.
- **Mention** — an inline bot reference.
- **Message** — one authored message.
- **MessageActions** — the per-message action row.
- **MessageAttachments** — files carried by a message.
- **MessageBubble** — the message surface itself.
- **MessageQuote** — a quoted excerpt of another message.
- **MessageScroller** — the scroll container and its anchoring.
- **MessageSideContext** — the side rail attached to a message.
- **PinnedMessages** — the pinned strip above the transcript.
- **Turn** — a full agent turn with its phases.

## Prompt

The composer.

- **PromptAttachButton** — starts an attachment.
- **PromptAttachments** — pending attachments in the composer.
- **PromptCommandMenu** — the slash-command menu.
- **PromptInput** — the composer field.
- **PromptMentionMenu** — the mention menu.
- **PromptReply** — the reply-to banner.

## Markdown

The payloads a turn renders.

- **Markdown** — the full renderer.
- **CodeBlock** — a highlighted, framed code block.
- **CodeSnippet** — the inline, chromeless variant.
- **MarkdownCode** — code inside the renderer.
- **MarkdownLink** — links inside the renderer.
- **MarkdownMath** — KaTeX blocks and inline math.
- **MarkdownMermaid** — diagrams.
- **MarkdownTable** — tables and their overflow.
- **MarkdownTaskCheckbox** — task-list checkboxes.

## Tools

The interruptions that need an answer.

- **ToolApproval** — approve or deny a tool call.
- **ToolQuestion** — the agent asks the reader.

## Routines

What a conversation runs on its own.

- **RoutinesPanel** — the routines of a conversation, on the trailing edge of its thread.
- **RoutineRow** — one routine, its trigger source, its switch and its deletion.
- **RoutineDetail** — one routine, its run history and the way to run it now.
- **RoutineForm** — the form a routine is created and edited in, inside the panel.
