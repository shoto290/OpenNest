# Branding

The product's identity marks — how a bot, a user or a space is recognised at a glance. Every mark derives deterministically from its seed so the same identity always renders the same.

## Components

- **AvatarGroup** — several identities stacked in one row.
- **Bot Avatar** — the generated animal-and-blot mark.
- **BotIdentityAvatar** — the bot mark with its activity and connection state.
- **SpaceTint** — the per-space accent applied to a subtree.
